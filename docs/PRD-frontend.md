## 1. 文档目标与阶段边界

### 1.1 本阶段目标

本阶段交付一个可在浏览器运行的响应式高保真交互原型，用于确定信息架构、页面布局、视觉系统、交互行为、响应式规则和用户可见状态。

原型使用确定性的本地假数据和本地媒体素材，不依赖真实接口。评审结论应能直接约束后续前端实现，不再把布局或关键交互留给实现阶段临时决定。

### 1.2 本阶段交付内容

| 范围 | 交付要求 |
| --- | --- |
| 公开端 | 首页、剧集、电影、搜索、详情和播放页面 |
| 用户端 | 登录、收藏和观看历史页面 |
| 管理端 | 仪表盘、目录、来源、字幕、弹幕审核和审计页面 |
| 交互 | 搜索、筛选、分页、收藏、恢复播放、选集、弹幕、表单和批量操作均可演示 |
| 状态 | 默认、加载、空、错误、无权限、长文本和图片失败状态均可切换 |
| 适配 | 移动端、平板、桌面和移动横屏播放器均可评审 |

### 1.3 明确不在本阶段考虑

- 不连接真实后端、数据库、对象存储或第三方服务。
- 不实现真实注册、登录、邮件发送、权限校验或管理员门禁。
- 不实现真实媒体解析、签名、来源可用性探测或播放进度同步。
- 不确定数据模型、接口契约、部署架构、缓存、安全或运维方案。
- 不实现上传、转码、抓取、实时通信或内容分发能力。

登录、收藏、弹幕审核和 CRUD 等操作只模拟用户可见流程。成功、失败和等待状态由本地场景控制器触发。

## 3. 设计方向与视觉规范

### 3.1 设计基线

根目录 [DESIGN.md](../DESIGN.md) 是本项目的设计指导。原型沿用其白色画布、近黑主操作、浅灰表面、克制强调色、清晰排版、4px 间距体系和分级圆角。

本项目不是营销站。设计语言需要适配高频浏览、媒体详情、播放器和管理工作台，优先保证内容可辨认、信息可扫描和操作效率。

### 3.2 项目视觉概念

视觉概念定为“社区影像档案”：整体像一个经过编辑整理的影视资料库，本地编辑式标题卡、项目后续提供的内容素材和元数据负责建立领域氛围，界面本身保持安静、明亮和精确。

不使用循环星空、霓虹渐变、扫描线、玻璃拟态、装饰性光球或整套 LCARS 仿制界面。不得用随机太空图库替代实际内容素材。

在正式品牌资产提供前，页头使用“Star Trek China / 星际迷航中国”纯文字锁定标识，不自行绘制、变形或拼接官方徽记。

### 3.3 对 DESIGN.md 的项目适配

| 项目 | 本项目规则 |
| --- | --- |
| 深色表面 | 除页脚外，仅播放器工作区可使用深色；浏览、详情、登录和后台保持白色或浅灰 |
| 字体 | Cal Sans 无可用授权时，拉丁标题使用 Manrope 600；中文使用 Noto Sans SC；界面拉丁字符回退 Inter |
| 字距 | 全站字距固定为 `0`，不使用负字距，避免中英文混排失真 |
| 触控尺寸 | 所有可点击控件最小命中区域为 `44×44px`，覆盖设计指导中的 36px 图标按钮基线 |
| 卡片 | 只用于单个媒体项目、摘要指标、模态工具和真实表单，不将页面区块包装成悬浮卡片 |
| 内容密度 | 首页保留较大留白；列表、播放和管理页面使用更紧凑的业务间距 |

| 层级 | 桌面 | 移动端 | 字重 | 用途 |

| Display | 48px / 1.1 | 32px / 1.15 | 600 | 首页品牌标题 |

| H2 | 28px / 1.2 | 24px / 1.25 | 600 | 页面区块标题 |

### 3.6 布局、间距与形状

- 公开页面内容最大宽度为 `1200px`，播放页为 `1440px`，管理端使用可用工作区宽度。
- 页面水平边距为移动端 `16px`、平板 `24px`、桌面 `32px`。
- 首页主要区块间距为桌面 `96px`、移动端 `64px`；列表和详情区块为 `64px`；后台区块为 `24px`。
- 使用 4px 间距基线：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96`。
- 按钮和输入框圆角 `8px`，媒体卡片 `12px`，主 Hero 媒体容器 `16px`。
- 胶囊圆角只用于标签、头像、圆形图标按钮和分段控件，不用于普通文字按钮。
- 页面分区使用留白、背景色或细分隔线，不使用卡片套卡片。
- 阴影仅用于 Dialog、Drawer、Popover 和拖浮状态；常规媒体卡片不使用重阴影。

### 3.7 图片、图标与动效

- 海报固定 `2:3`，集缩略图固定 `16:9`，桌面横幅固定 `21:9`，移动端横幅提供独立 `16:9` 构图。
- 默认标题卡必须完整显示中文标题、原名和内容编号，并在四周保留 12% 安全区；移动端使用单独排版，不裁切桌面标题卡。
- 后续替换为正式内容素材时使用 `object-fit: cover`，但人物面部、片名和关键主体不得被裁掉。
- 内容视觉必须能通过标题或主体辨认具体作品，不使用模糊、过暗或纯氛围图片充当主图。
- 图片失败时显示浅灰占位、内容类型图标和完整标题，不改变原容器尺寸。
- 界面图标统一使用 Lucide。陌生图标提供 Tooltip，所有图标按钮提供中文可访问名称。
- 动效时长只使用 `120ms`、`180ms` 和 `280ms`。仅用于浮层、收藏反馈、页头状态和容器内不超过 `1.03` 的图片缩放。
- 不使用自动轮播、视差、页面级滚动揭示或装饰动画。启用减少动效时关闭位移和缩放，并默认关闭弹幕。

## 4. 信息架构与路由

```text
/
├── /series
│   ├── /series/[id]
│   └── /series/[id]/season/[number]
├── /movies
│   └── /movies/[id]
├── /search?q=[keyword]&type=[all|series|movie|episode]
├── /watch/episode/[id]
├── /watch/movie/[id]
├── /login?returnTo=[path]&intent=[favorite|danmaku]
├── /favorites
├── /history
└── /admin
    ├── /admin/catalog
    │   ├── /admin/catalog/series
    │   │   ├── /admin/catalog/series/new
    │   │   ├── /admin/catalog/series/[seriesId]
    │   │   ├── /admin/catalog/series/[seriesId]/edit
    │   │   └── /admin/catalog/series/[seriesId]/seasons
    │   │       ├── /new
    │   │       └── /[seasonId]
    │   │           ├── /edit
    │   │           └── /episodes
    │   │               ├── /new
    │   │               └── /[episodeId]/edit
    │   └── /admin/catalog/movies
    │       ├── /new
    │       └── /[movieId]/edit
    ├── /admin/sources
    │   ├── /admin/sources/new
    │   └── /admin/sources/[id]/edit
    ├── /admin/subtitles
    │   ├── /admin/subtitles/new
    │   └── /admin/subtitles/[id]/edit
    ├── /admin/danmaku
    └── /admin/audit
```

`/series/[id]/season/[number]` 复用系列详情页，只改变当前选中季，便于分享和返回。不存在独立单集详情页，也不使用无法区分内容类型的 `/watch/[id]`。

访问 `/series/[id]` 时，有观看进度的用户默认选择最近观看单集所属季；其他用户选择最早包含可播放单集的季；全季均不可播放时选择第 1 季。确定后使用 URL replace 进入对应季深链接，不产生额外返回历史。

`/admin/catalog` 默认进入 `/admin/catalog/series`。管理端季路由始终包含 `seriesId`，单集路由始终同时包含 `seriesId` 和 `seasonId`，确保独立访问时仍有完整层级上下文。

### 4.1 页面壳层

| 壳层 | 页面 | 规则 |
| --- | --- | --- |
| Public Shell | 首页、列表、详情、搜索、收藏、历史 | 64px 顶部导航 + 主内容 + 深色页脚 |
| Watch Shell | 单集和电影播放页 | 56px 精简顶栏 + 播放工作区，不显示页脚 |

| Admin Shell | 全部管理页 | 响应式侧边导航 + 顶部工具栏 + 浅灰工作区，不显示公开端页脚 |

## 5. 全局组件与交互规则

### 5.1 顶部导航

- 高度 `64px`，默认白底，吸顶后增加底部 Hairline，不使用透明玻璃效果。
- 左侧为文字品牌标识；中间为首页、剧集、电影；右侧为搜索、收藏入口和用户菜单。
- 当前导航项使用字体加深和底部 2px 指示线，不能只改变颜色。
- 访客显示“登录”主按钮；用户显示头像菜单，菜单包含“我的收藏”“观看历史”“退出登录”。
- 移动端保留品牌、搜索和菜单图标。主导航与用户入口放入全屏 Sheet，点击链接或按 Esc 后关闭。

### 5.2 全局搜索入口

- 桌面端打开宽度 `min(720px, calc(100vw - 32px))` 的 Command Dialog；移动端打开全屏 Sheet。
- 输入一个非空字符后显示建议，最多 8 条，按系列、电影和单集分组。
- 每条建议包含缩略图、标题、原名或季集编号、年份和类型标签。
- 支持方向键移动、Enter 进入、Esc 关闭；中文输入法组合期间 Enter 不触发提交。
- 无建议时显示“未找到匹配内容”和“查看全部结果”；提交后进入搜索页并保留关键词。

### 5.3 页脚

- 使用 `#101010` 深色背景，包含品牌、站点说明、社区链接和内容免责声明。
- 链接分为“浏览”“账户”“关于”三组，桌面三列，移动端单列。
- 页脚不承担主要导航，不显示无效联系方式或占位链接。

### 5.4 媒体卡片

- 系列和电影使用海报卡片；继续观看和单集使用 `16:9` 横向卡片或列表行。
- 海报下方依次显示标题、原名或年份、必要标签。标题区域固定两行高度，避免网格跳动。
- 收藏按钮是与整卡链接相邻的独立图标按钮，不能嵌套在链接内；触屏端始终可见。
- Hover 或键盘聚焦只增加 Hairline 和轻微图片缩放，不出现仅桌面可用的隐藏操作。
- 有进度时在图片底部显示 4px 进度条，并用文本提供当前集或剩余时间。

### 5.5 筛选与分页

- 桌面筛选即时生效；移动端在底部 Drawer 中暂存，点击“应用”后生效。
- 筛选项固定为年份、类型标签和排序。排序选项为“最近更新”“首播年份”“标题”。
- 已生效条件显示为可移除标签，并提供“全部清除”。
- 筛选、排序和页码始终反映在 URL 中；切换筛选后回到第 1 页。
- 剧集和电影列表固定每页 12 项，搜索结果固定每页 10 项，所有断点使用相同分页容量。
- Pagination 显示上一页、下一页、当前页和必要的省略项；首尾页对应按钮禁用。

### 5.6 反馈和通用状态

| 状态 | 展示规则 |
| --- | --- |
| 页面加载 | 保留最终布局尺寸的 Skeleton，不显示全屏 Spinner |
| 局部提交 | 操作按钮进入 Spinner + 禁用状态，原内容保持可见 |
| 空状态 | Empty + 对应原因 + 单一下一步操作 |
| 字段错误 | 输入框下方内联错误，并聚焦首个错误字段 |
| 单次操作失败 | Toast，包含明确结果和可执行的重试或撤销 |
| 区块失败 | 区块内 Alert + 重试按钮，不影响其他区块 |
| 页面失败 | 页面级错误说明 + 重试 + 返回安全入口 |
| 无权限 | 403 状态页，提供返回首页或返回上一页 |
| 不存在 | 404 状态页，提供搜索和返回首页 |

## 6. 页面级规格

### 6.1 首页 `/`

**目标：** 让用户第一屏确认站点身份、看到一项重点内容，并快速进入继续观看或内容浏览。

**页面结构：**

1. 单张固定 Hero，不轮播、不自动播放背景视频。
2. 已登录且有历史时显示“继续观看”。
3. “最近更新”混合展示电影和最新单集。
4. “社区精选系列”展示系列海报。
5. “精选电影”展示电影海报。
6. 深色页脚。

**Hero 规格：**

- 使用可辨认的重点内容横幅作为全宽背景，桌面 `21:9`，移动端使用独立 `16:9` 素材。
- 内容区包含 H1“Star Trek China 视频站”、重点内容标题、两行简介和两个操作。
- 主操作按进度显示“立即播放”或“继续观看”，次操作为“查看详情”。
- 文字位于一致的半透明纯色遮罩上，不使用渐变遮罩，不遮挡作品关键主体。
- Hero 高度需让 `360×800` 与 `1440×900` 视口都露出至少 80px 的下一内容区。

**内容行交互：**

- 桌面每次点击左右箭头滚动约一屏；到达首尾时对应箭头禁用。
- 移动端使用原生横向滑动，并露出下一张卡片的一部分提示可滚动。
- 访客直接省略“继续观看”，不插入登录宣传卡。
- 区块无数据时整段省略；页面所有内容为空时显示全页 Empty。

### 6.2 剧集列表 `/series` 与电影列表 `/movies`

**目标：** 支持快速扫描、筛选和进入详情。

**页面结构：**

1. H1、简短说明和当前结果数。
2. 桌面内联筛选栏或移动端“筛选”按钮。
3. 已生效条件区。
4. 海报网格。
5. 分页。

**布局：**

- `320-767px` 为 2 列，`768-1023px` 为 4 列，`1024-1279px` 为 5 列，`>=1280px` 为 6 列。
- 卡片比例、标题高度和元数据高度固定，图片加载和收藏切换不得引起网格位移。
- 电影卡显示年份和时长；系列卡显示首播年份和季数。

**边界状态：**

- 无筛选结果时保留筛选区，显示“清除筛选”。
- 全站无内容时显示返回首页，不展示分页。
- 不可播放不影响进入详情，但在卡片元数据中显示“暂不可播放”。

### 6.3 系列详情 `/series/[id]` 与季深链接

**目标：** 展示系列信息，帮助用户选择季和单集，并明确下一次播放动作。

**页面结构：**

1. 横幅详情头部：横幅、海报、标题、原名、年份、标签、简介和操作。
2. 季导航。
3. 当前季简介和集列表。
4. 相关推荐。

**详情头部：**

- 桌面海报固定约 `240×360px`，与信息区共同位于横幅之上；移动端缩小海报并纵向排列。
- 主按钮按状态显示“播放 S01E01”“继续观看 S02E04”或“重新观看”。
- 收藏是图标加文字的次操作，只收藏整个系列。
- 系列无可播放单集时主按钮禁用，并在旁边显示“当前暂无可播放内容”。

**季与集列表：**

- 桌面不超过 8 季时使用 Tabs，超过 8 季时使用 Select；移动端始终使用 Select。
- 切换季后更新 URL、季简介和集列表，并将焦点移到当前季标题。
- 集条目显示缩略图、`SxxExx`、标题、简介、时长、播放状态和观看进度。
- 移动端隐藏集简介，但保留集号、标题、时长和进度。
- 点击可播放条目进入 `/watch/episode/[id]`；不可播放条目保持可聚焦并说明原因。
- 不提供“本季全选收藏”或“标记全部已看”。

### 6.4 电影详情 `/movies/[id]`

**目标：** 展示电影完整信息并引导播放或继续观看。

**页面结构：**

1. 与系列详情一致的横幅详情头部。
2. 标题、原名、年份、时长、标签、简介和观看能力标签。
3. “立即播放”“继续观看”或“重新观看”主按钮。
4. 收藏次操作。
5. 相关推荐。

观看能力只显示用户能理解的“1080p”“中文字幕”“含弹幕”等信息。页面不展示底层 provider、路径或技术来源名，多清晰度选择只出现在播放器内。

电影不可播放时，主按钮保持禁用并显示“当前暂无可播放来源”，次操作提供“返回电影列表”。收藏仍可使用。

### 6.5 搜索页 `/search`

**目标：** 在一个结果页中查找系列、电影和具体单集。

**页面结构：**

2. 类型 Tabs：全部、系列、电影、单集。
3. 结果数量和当前筛选说明。
4. 统一纵向结果列表。

**结果条目：**

### 6.6 播放页 `/watch/episode/[id]` 与 `/watch/movie/[id]`

**目标：** 提供完整、可演示且跨设备稳定的观看体验。

**页面结构：**

1. 精简顶栏：返回、当前标题、收藏或更多操作。
2. 播放器工作区。
3. 单集选集侧栏或移动端 Drawer。
4. 播放器下方弹幕输入条。
5. 标题、元数据、简介和上一集/下一集操作。
6. 相关推荐。

**桌面布局：**

- `>=1280px` 时播放器与 `336px` 选集侧栏并排且等高，整体不超过 `1440px`。
- `<1280px` 时不保留常驻侧栏，顶栏和播放器下方均提供“选集”按钮，通过底部 Drawer 展示完整集列表。
- 电影不显示选集侧栏，播放器居中并限制最大观看宽度。
- 播放区背景使用 `#101010`，工具面板使用 `#1A1A1A`，正文信息区恢复白色画布。

**播放器能力：**

- 使用 Artplayer 展示本地演示视频，原型至少包含可播放样例、一个 WebVTT 字幕和一组时间轴弹幕。
- 控制项包括播放、暂停、进度、音量、全屏、画中画、倍速、字幕、清晰度和弹幕开关。
- 清晰度显示“自动”“1080p”“720p”；字幕显示“关闭”“简体中文”“English”。
- 切换清晰度时保持当前时间点、播放状态、音量、倍速、字幕和弹幕设置。
- 浏览器阻止自动播放时显示明确的播放按钮，不把该情况表现为错误。

**选集与结束状态：**

- 选集列表显示当前季、集号、标题、时长和进度，当前集高亮并自动滚动到可见位置。
- 上一集或下一集不存在时对应按钮禁用并说明“已是第一集”或“已是最后一集”。
- 单集播放结束后显示 10 秒下一集倒计时，可立即播放或取消；电影结束后显示重新播放和相关推荐。

**观看历史与恢复：**

- 有进度时，用户首次开始播放后恢复至假数据时间点，并显示“已从 12:34 继续播放”。
- 用户可选择“从头播放”，当前原型会话内的进度同步更新到首页、历史和选集列表。
- 访客不显示跨页面历史，但当前页面刷新前可保留播放位置。

**弹幕交互：**

- 已审核弹幕按视频时间轴滚动，不使用“实时在线”措辞。
- 设置 Popover 包含显示开关、字号“小/中/大”、透明度和显示区域“全屏/上半屏”。
- 访客输入区显示“登录后发送弹幕”，点击后进入带 `returnTo` 和 `intent=danmaku` 的登录页。
- 用户输入上限 80 个字符。Enter 提交，Shift+Enter 不提交；中文输入法组合期间 Enter 不触发。
- 提交中禁用输入；成功后清空并显示“已提交，审核通过后公开”。当前用户可看到一次本地预览，但不混入已审核公共数据。
- 失败时保留输入内容并提供重试。无弹幕时播放器正常工作，设置与投稿入口仍保留。

**播放器状态：**

| 状态 | 表现 |
| --- | --- |
| 初始 | 海报帧 + 居中播放按钮 |
| 加载或缓冲 | 播放器内 Spinner，不遮挡退出全屏操作 |
| 暂停 | 保留画面和控制层，不显示营销内容 |
| 恢复播放 | Toast 提示恢复时间点 |
| 来源切换 | 轻量加载状态，时间点不回退 |
| 单来源失败 | 错误层 + 重试 + 切换其他清晰度 |
| 全部来源失败 | 错误层 + 返回详情页，不暴露技术错误信息 |
| 无字幕 | 字幕菜单显示“暂无字幕”且禁用 |
| 播放结束 | 单集下一集倒计时；电影显示重播与相关推荐 |

**移动端：**

- 竖屏播放器贴近视口两侧并保持 `16:9`，页面其余内容保留 16px 边距。
- 低优先级控制收入“更多”菜单；选集放入底部 Drawer。
- 横屏 `844×390` 时，56px 顶栏自动收起，视频在剩余视口内保持 `16:9` 并居中，余量使用黑色留边，不裁切画面。控制层、字幕和弹幕不能互相遮挡。

### 6.7 登录页 `/login`

**目标：** 完成可演示的登录选择，并在成功后返回触发登录的页面。

**页面结构：**

- 使用浅灰页面背景和最大宽度 `420px` 的白色登录工具卡。
- 顶部显示品牌标识和“登录以同步收藏、历史和弹幕投稿”。
- 第一操作为“使用 GitHub 登录”。
- 分隔后提供邮箱输入和“发送登录链接”。
- 底部提供返回来源页或首页的文本链接。

**状态：**

- 默认、邮箱格式错误、提交中、邮件已发送、发送失败和重新发送倒计时。

- `intent=favorite` 成功后自动完成原收藏并显示 Toast；`intent=danmaku` 成功后返回播放页、打开并聚焦弹幕输入框，不自动发送任何内容。

取消收藏后立即从列表移除，并显示 5 秒“撤销”Toast。批量取消需要确认；退出管理模式时清空选择。空状态提供“浏览剧集”和“浏览电影”两个明确入口。

### 6.10 管理后台 `/admin/*`

**目标：** 用高密度但清晰的工作台演示内容维护和审核流程，不承担真实数据管理。

#### 6.10.1 管理壳层

- 桌面左侧固定 `240px` 白色侧边导航，右侧为浅灰工作区；侧边栏与内容区使用 Hairline 分隔。
- `768-1279px` 侧边栏收缩为 `72px` 图标导航；移动端通过 Sheet 打开完整导航。
- 顶部工具栏显示当前页面标题、面包屑和管理员菜单。
- 当前菜单项使用浅灰 pill 背景、图标和文字加深，不使用大面积品牌色。
- 管理端不显示公开端页脚。

coss ui 的 Sidebar 本地文档缺失，因此管理侧栏由语义 `nav`、Scroll Area、Tooltip 和响应式 Sheet 组合。

#### 6.10.2 仪表盘 `/admin`

- 第一行展示系列、电影、来源和待审核弹幕四个摘要指标，分别进入系列列表、电影列表、来源列表和待审核弹幕列表。
- 主区域展示“待审核弹幕”快捷列表和“最近操作”列表。
- 每个摘要只提供一个明确目标页面入口，不绘制无数据依据的趋势图。
- 加载、全部为零、局部失败和无权限状态均可切换。

#### 6.10.3 目录管理 `/admin/catalog`

- `/admin/catalog` 默认跳转至系列列表。顶层 Tabs 固定为“系列”和“电影”，各自提供搜索、状态筛选、排序和新建按钮。
- 系列列表列为标题、首播年份、季数、单集数、展示状态、更新时间和操作。操作为“管理季与单集”“编辑”“预览公开页”“删除”。
- 系列工作区 `/admin/catalog/series/[seriesId]` 显示系列摘要和季列表。季列表列为季号、季标题、单集数、展示状态、更新时间和操作。
- 季工作区 `/admin/catalog/series/[seriesId]/seasons/[seasonId]` 显示季摘要和单集列表。单集列表列为集号、标题、时长、可播放状态、展示状态、更新时间和操作。
- 季操作为“管理单集”“编辑”“删除”；单集操作为“编辑”“预览播放页”“删除”。不可播放单集的预览操作禁用并说明原因。
- 电影列表列为标题、年份、时长、可播放状态、展示状态、更新时间和操作。操作为“编辑”“预览公开页”“删除”，不设置独立管理详情页。
- 系列和季工作区使用 Breadcrumb 展示“系列 > 当前系列 > 当前季”，不在一个表格中平铺所有层级。
- 所有行操作放入 Menu，删除使用 Alert Dialog。公开预览在新标签打开对应前台路由。
- 新建和编辑使用独立页面，保存、取消和未保存离开确认均可演示。

**目录表单字段：**

| 类型 | 字段 |
| --- | --- |
| 系列 | 中文标题、原名、首播年份、简介、类型标签、海报、横幅、展示状态 |
| 季 | 季号、季标题、简介、海报、展示状态 |
| 单集 | 集号、标题、原名、简介、时长、首播日期、缩略图、展示状态 |
| 电影 | 中文标题、原名、年份、时长、简介、类型标签、海报、横幅、展示状态 |

图片上传只演示选择、预览、替换、移除、上传中和失败状态。必填、格式和重复编号错误均在字段下方展示。

#### 6.10.4 来源管理 `/admin/sources`

- 表格列为关联内容、来源类型、质量标签、状态、更新时间和操作。
- 筛选包含内容类型、来源类型、质量和状态。
- 来源只能关联单集或电影。表单通用字段为关联内容、来源类型、显示标签、清晰度和是否启用。
- 原型中的来源类型固定为“公开链接”“R2 对象”“RustFS”“OpenList”，只用于确定管理表单的可见选项，不定义存储或接入方案。
- “公开链接”显示 URL；“R2 对象”显示对象路径；“RustFS”和“OpenList”显示资源地址。切换类型时替换对应字段，并保留通用字段。
- URL 必须以 `https://` 开头，对象路径不能为空，资源地址错误时显示字段级错误。原型只演示这些前端校验，不发起探测。
- 公开端从不显示 `public_url`、`r2`、`rustfs` 或 `openlist` 等内部类型名。

#### 6.10.5 字幕管理 `/admin/subtitles`

- 表格列为关联内容、语言、显示标签、默认状态、启用状态和更新时间。
- 表单字段为关联内容、语言、显示标签、字幕文件、设为默认和是否启用。
- 上传演示文件名、大小、替换、移除、解析中、格式错误和成功状态。
- 同一内容只能有一个默认字幕；冲突时以表单错误说明，不静默覆盖。

#### 6.10.6 弹幕审核 `/admin/danmaku`

- 顶部显示待审核、已通过和已隐藏数量，状态切换使用 Tabs。
- 筛选包含关键词、关联内容和提交时间。
- 桌面使用列表与内容预览双栏布局；预览显示时间点、上下文标题和模拟视频帧。
- 单条操作为通过、隐藏和删除；删除必须二次确认。
- 多选后显示固定批量工具栏，可批量通过或隐藏；批量删除不纳入原型。
- 状态固定为“待审核”“已通过”“已隐藏”。删除后条目移出列表，不作为可筛选状态展示。
- 双栏预览仅用于 `>=1280px`。更窄视口点击条目后使用 Drawer 展示内容预览和审核操作。

#### 6.10.7 审计日志 `/admin/audit`

- 只读表格列为时间、操作人、操作、对象和结果。
- 支持日期、操作类型和关键词筛选，详情通过 Drawer 展示结构化字段。
- 不提供删除、编辑或导出操作。

#### 6.10.8 后台表格与响应式规则

- 桌面表头吸顶，默认行高 `52px`，数字右对齐，状态使用 Badge。
- 批量操作只在有选中项时出现；取消选择后工具栏立即消失。
- `>=1280px` 展示完整表格；`1024-1279px` 隐藏低优先级列，只保留名称、状态、更新时间和操作。
- `<1024px` 不强行横向滚动表格，改为标签和值组成的记录列表，主操作常驻，次操作收入 Menu。
- `768-1023px` 使用 72px 管理侧栏与记录列表；`<768px` 使用导航 Sheet 与记录列表。
- 所有保存、删除和批量操作均包含提交中、成功和失败状态。

## 7. 关键用户流程

| 流程 | 演示路径 | 完成标准 |
| --- | --- | --- |
| 浏览到播放 | 首页 → 剧集列表 → 系列详情 → 选季 → 单集播放 | 播放器启动并高亮当前集 |
| 搜索到播放 | 全局搜索 → 单集建议或搜索页 → 播放 | 关键词保留，目标内容正确 |
| 恢复播放 | 首页继续观看或历史 → 播放页 | 恢复假数据进度，可从头播放 |
| 收藏 | 详情页收藏 → 我的收藏 → 取消 → 撤销 | 各入口状态同步 |
| 登录返回 | 访客点击收藏或弹幕 → 登录 → 成功 | 返回原页面并完成原操作入口 |
| 弹幕投稿 | 播放 → 输入 → 提交 → 成功或失败 | 成功反馈明确，失败保留文字 |
| 目录维护 | 后台目录 → 新建或编辑 → 校验 → 保存 | 返回列表并看到本地变更 |
| 弹幕审核 | 待审核 → 预览 → 单条或批量通过 | 数量和列表状态同步 |

| `<768px` | 移动导航、2 列海报、筛选 Drawer、单列详情、选集 Drawer、后台记录列表 |
| `768-1023px` | 4 列海报、紧凑导航、详情双列、选集 Drawer、72px 管理侧栏和记录列表 |
| `1024-1279px` | 完整公开导航、5 列海报、桌面筛选、选集 Drawer、紧凑管理表格 |
| `>=1280px` | 6 列海报、完整管理侧栏、播放器与选集并排 |

### 8.2 固定验收视口

- 移动端：`360×800`。
- 平板：`768×1024`。
- 桌面：`1440×900`。
- 播放器横屏：`844×390`。
- 最小宽度烟测：`320×568`。
- 最低支持宽度：`320px`。

主验收浏览器为项目环境中的最新稳定版 Chromium，移动与横屏视口使用 Chromium 设备模拟。全屏和画中画在浏览器不支持时隐藏入口，不显示无法执行的按钮。

所有验收视口不得出现页面级横向滚动、文本溢出、控件遮挡、图片比例跳变或依赖 Hover 才能完成的操作。

## 9. 无障碍与输入方式

- 原型目标为 WCAG 2.2 AA；正文对比度至少 `4.5:1`，大字和控件边界至少 `3:1`。
- 所有点击目标至少 `44×44px`，键盘焦点清晰且不被吸顶导航或浮层遮挡。
- 使用正确的 `header`、`nav`、`main`、`footer`、标题层级和跳过导航链接。
- 整卡链接与收藏按钮必须是相邻交互元素，不能嵌套按钮或链接。
- Hover 能力在键盘聚焦时等价出现，在触屏上有常驻入口。
- Dialog、Drawer、Menu 和 Popover 打开后管理焦点，关闭后恢复到触发器。
- 图片替代文本描述完整内容标题；纯装饰遮罩和背景使用空替代文本。
- 视频控件提供中文名称与当前值；字幕至少有一个可演示轨道。
- 滚动弹幕对屏幕阅读器隐藏，投稿结果通过独立 `aria-live="polite"` 区域播报。
- 中文输入法组合期间，Enter 不触发搜索、表单提交或弹幕发送。
- 启用 `prefers-reduced-motion` 时关闭位移和缩放，并默认关闭弹幕。

## 10. 假数据与原型场景

### 10.1 数据基线

原型使用固定日期、固定排序和确定性本地数据，不得在渲染时随机生成。截图和重复评审必须得到相同结果。

至少准备：

- 14 个系列、18 部电影，确保两个列表都能演示分页。
- 1 个包含 3 季且每季 8 集的完整系列。
- 1 个超过 8 季的系列，用于验证 Select 降级。
- 6 条观看历史、4 个收藏。
- 40 条已审核公共弹幕。
- 18 条管理端弹幕记录，其中待审核 8 条、已通过 6 条、已隐藏 4 条，足以演示多选和批量审核。
- 1 个可播放本地视频、2 个模拟清晰度、1 个 WebVTT 字幕文件。

数据必须覆盖超长中英文标题、无原名、无简介、图片失败、不可播放、无字幕、无弹幕、多清晰度、进度为 0、中途和已完成等边界。

默认素材不等待外部品牌包。原型使用固定的本地编辑式标题卡：作品标题、内容编号、年份和四组预设底色构成海报与横幅，不使用官方 Logo、剧照或人物肖像。

内容底色只使用 `#111111`、`#3B82F6`、`#FB923C` 和 `#34D399`，按内容排序循环分配。深色底使用白字，浅色底使用 `#111111`，不在运行时随机生成。

素材路径固定为 `/prototype/assets/{posters|backdrops|thumbnails}/[content-id].webp`。后续获得可合法使用的正式素材时，只按相同比例替换文件，不调整页面布局。

视频、字幕和弹幕 fixture 同样存放在仓库内，不依赖远程随机资源。

### 10.2 人设与场景切换

原型提供评审专用场景参数：

```text
?persona=guest|user|admin
&scenario=default|loading|empty|error|long-copy|image-failed|forbidden
&playerState=initial|buffering|resume|source-failed|all-sources-failed|no-subtitles|no-danmaku|ended
&authState=default|invalid-email|submitting|sent|send-error|cooldown
&adminState=default|selected|dirty|validation-error|submitting|delete-confirm|action-error
```

`scenario` 每次只取一个全局页面状态，`error` 固定表示页面级加载失败。只要 `scenario` 不是 `default`，页面就忽略 `playerState`、`authState` 和 `adminState`。

当 `scenario=default` 时，每个页面只读取与自身匹配的一个专用状态参数。不适用于当前页面的参数被忽略并回退到该页默认状态，因此任意参数组合都有唯一结果。

| 页面组 | 全局 `scenario` | 专用状态（仅在 `scenario=default` 时） |
| --- | --- | --- |
| 首页、列表、详情、搜索 | default、loading、empty、error、long-copy、image-failed | 无 |
| 登录 | default、error | 全部 `authState` |
| 收藏、历史 | default、loading、empty、error、forbidden | 无 |
| 播放页 | default、loading、error、long-copy | 全部 `playerState` |
| 管理仪表盘 | default、loading、empty、error、forbidden | 无 |
| 目录、来源、字幕列表 | default、loading、empty、error、forbidden | delete-confirm、action-error |
| 弹幕审核 | default、loading、empty、error、forbidden | selected、delete-confirm、action-error |
| 审计列表 | default、loading、empty、error、forbidden | 无 |
| 管理新建与编辑表单 | default、loading、error | dirty、validation-error、submitting、action-error |

## 11. 组件策略

### 11.1 coss ui 使用原则

所有适用的交互原语优先使用 coss ui。产品级组合组件允许基于 coss ui 与 Base UI 组合，不再以“所有视觉块必须是现成 coss ui 组件”作为验收条件。

| 场景 | 组件 |
| --- | --- |
| 导航与层级 | Breadcrumb、Menu、Sheet、Drawer、Tabs、Scroll Area |
| 搜索与筛选 | Command、Autocomplete、Combobox、Select、Checkbox、Input |
| 操作与反馈 | Button、Tooltip、Toast、Alert、Alert Dialog、Spinner |
| 表单 | Form、Field、Fieldset、Input、Textarea、Switch、Radio Group |
| 数据展示 | Table、Badge、Pagination、Progress、Skeleton、Empty |
| 浮层 | Dialog、Popover、Sheet、Drawer |

### 11.2 项目组合组件

- `SiteHeader`、`SiteFooter`、`SearchCommand`。
- `FeaturedHero`、`ContentRail`、`MediaCard`、`EpisodeRow`。
- `PlayerShell`、`EpisodePanel`、`DanmakuComposer`、`DanmakuSettings`。
- `AccountTabs`、`HistoryRow`、`BulkActionBar`。
- `AdminNav`、`AdminTable`、`MediaAssetField`、`ModerationPreview`。

播放器使用 Artplayer；HLS 演示可使用 hls.js；弹幕展示使用 `artplayer-plugin-danmuku`。这些属于媒体领域组件，不由 coss ui 替代。

## 12. 交付顺序与验收

### 12.1 原型批次

| 批次 | 页面 | 评审重点 |
| --- | --- | --- |
| P1 浏览路径 | 首页、列表、系列详情、电影详情、搜索 | 视觉系统、信息密度、浏览与筛选 |
| P2 播放路径 | 单集和电影播放页 | 播放器、选集、字幕、弹幕和移动横屏 |
| P3 用户路径 | 登录、收藏、观看历史 | 登录返回、状态同步、空状态和批量操作 |
| P4 管理路径 | 仪表盘、目录、来源、字幕、弹幕、审计 | 工作台密度、表单、表格和审核效率 |

四批均属于前端高保真原型最终范围，不代表后端开发顺序。

### 12.2 验收标准

1. 信息架构中的每条路由可直接访问，主导航和关键流程无死链。
2. 本文列出的搜索、筛选、分页、收藏、恢复播放、选集、弹幕、表单和批量操作均可用本地状态完整演示。
3. 访客、用户和管理员三种人设，以及默认、加载、空、错误、无权限、长文本和图片失败状态均可复现。
4. `320×568`、`360×800`、`768×1024`、`1440×900` 和 `844×390` 视口无非预期横向滚动、遮挡、文本溢出或布局跳动。
5. 视觉令牌、字体层级、间距、圆角、图片比例和深色表面使用符合 `DESIGN.md` 与本 PRD 的适配规则。
6. 所有 Hover 操作均有键盘和触屏等价入口，焦点、Dialog、Drawer、对比度和减少动效规则通过人工检查。
7. 播放页可实际播放本地样例，并能演示字幕、弹幕、清晰度切换、恢复进度、失败和结束状态。
8. 原型不依赖真实后端或远程随机素材，刷新后默认场景稳定，无未处理的控制台错误。

## 13. 已锁定设计决策

| 决策项 | 结论 |
| --- | --- |
| 原型载体 | 浏览器可运行的响应式交互原型 |
| 首页 Hero | 单张固定内容横幅，不轮播 |
| 整体主题 | 明亮内容目录；深色只用于播放器工作区和页脚 |
| 季详情 | 系列页内切换，季路由只作为同布局深链接 |
| 默认季 | 优先最近观看季，否则最早可播放季，否则第 1 季 |
| 单集详情 | 不设置，直接进入单集播放页 |
| 电影路由 | 统一使用 `/movies/[id]` |
| 播放路由 | `/watch/episode/[id]` 与 `/watch/movie/[id]` 分开 |
| 搜索范围 | 系列、电影和单集；季不作为独立结果 |
| 收藏范围 | 系列和电影 |
| 历史范围 | 单集和电影 |
| 清晰度与来源 | 公开端只显示自动和清晰度；内部来源名只在后台出现 |
| 弹幕设置 | 完整演示开关、字号、透明度和显示区域 |
| 后台表单 | 新建和编辑使用独立页面；Dialog 只用于确认 |
| 后台目录 | 顶层为系列和电影，系列内部使用面包屑管理季与单集 |
| 组件约束 | 优先 coss ui，领域组合组件按本 PRD 自行组合 |
| 原型内容素材 | 使用固定本地编辑式标题卡，正式素材只做等比例替换 |

本版本不保留影响原型制作的开放设计问题。品牌 Logo 和正式内容素材未提供时，按本文定义的文字标识与本地合法 fixture 执行，不阻塞布局评审。
